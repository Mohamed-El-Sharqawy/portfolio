## The brief

A full learning-management system for a national police academy: students, instructors and administrators working in one product, each with a different level of access.

## My part

With the team I built the **student–instructor chat**, the **academic statistics dashboards**, and the **secure multi-level access** model that decides what each role can see and do.

## How it was built

- **Next.js 16 + React 19** with **TypeScript**.
- **Zustand** for client state and **React Query** for server state and caching.
- **Tailwind CSS** for the interface, **NestJS** on the backend.

## Outcome

Academy operations — teaching, communication and reporting — running at national scale on one platform.
