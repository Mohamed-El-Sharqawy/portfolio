## The brief

Ride-hailing in Egypt deserves an Arabic-first product: a rider app that feels native on local devices, an operations dashboard RTL users can actually work in all day, and a backend that keeps matching, trips, and driver state consistent under real load.

## My part

I designed and built the platform end to end as a personal project: the rider app, the admin dashboard, and the microservices backend, in one Turborepo monorepo.

## How it was built

- **Expo + React Native** rider app, typed end to end with **TypeScript**.
- **Arabic-first RTL admin dashboard** built for daily operations use.
- **Event-driven microservices** communicating over **NATS**, with **Redis** and **OSRM** routing for trip matching and ETAs.

## Outcome

A complete ride-hailing stack — client, operations, and backend — in a single monorepo, ready to grow city by city.
